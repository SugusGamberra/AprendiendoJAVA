# VARIABLES

## Introducción

Las variables se usan para guardar datos que el programa necesita durante la ejecución (números, textos, fechas...). Son como cajitas donde guardas información temporal.

## Estructura de la variable

- Nombre: Cómo la identificas (let usuario, const pi, let edad...)
- Tipo de datos que almacena: 
    - String: Texto "Hola"
    - int: Numeros enteros 10
    - double: Números decimales 3.21
    - boolean: Valores lógicos (true or false)
    - char: Un solo caracter 'a'
    - Hay muchos más, iremos viendo a medida que creemos cositas!
- Valor: Lo que guarda la variable

## Declarar una variable

Para declarar (crear) una variable en JAVA le decimos que tipo de valor almacena, el nombre y el valor, su fórmula seria tipoDeDato nombreVariable = valor;.

Aquí el = no es como en mates, significa "oye mi variable almacena este valor".

Ejemplo de variables:

String nombre = Illidan;

int edad = 1;

double precio = 5.99;

char simbolo = '$';

Podrías mostrarlo en consola usando:

System.out.println(nombre);

## Concatenar

Para usar varias variables a la vez o trozos de texto mezclados con variables lo haríamos de la siguiente forma:

System.out.println("Hola! Me llamo " + nombre + " y tengo menos de " + edad + " años... Mi mamá me compró unas gotitas para mi ojito enfermo que costaron " + precio + simbolo);
