# ☕ Fundamentos de Programación con Java [![Java](https://img.shields.io/badge/Java-%23ED8B00.svg?logo=openjdk&logoColor=white)](#) 🚀

Vamos a aprender a programar desde 0 enfocándonos en JAVA, uno de los lenguajes más popus :P

Son lecciones prácticas y directas destinadas que nacen de la inspiración de ayudar a mis compis de clase o para cualquiera que quiera poner sus piececitos en el mundo de picotear códigos!  

## Qué necesitas antes de empezar? 🛠️

Asegúrate de tener instalado:

1. JDK (java development kit): https://www.oracle.com/es/java/technologies/downloads (te recomiendo la última versión disponible, elige tu SO y de ahí te lo bajas e instalas)
2. IDE: Recomiendo Eclipse (es el que yo uso) pero puedes usar IntelliJ IDEA Community Edition o Visual Studio Code con la extensión de Java! 
    - Eclipse: https://eclipseide.org
    - Intellij IDEA: https://www.jetbrains.com/idea/download/?section=windows
    - VS Code: https://code.visualstudio.com
