## 🚀 Requisitos previos

- 💻 **IDE recomendado:** [Eclipse IDE](https://eclipseide.org) (versión para desarrolladores Java).  
- ☕ **JDK:** Instala el [Java Development Kit (JDK)](https://www.oracle.com/es/java/technologies/downloads) — versión 17 o superior.  

> 🔧 **Consejo**: abre Eclipse, crea un nuevo *Java Project*, y copia el código de los ejemplos dentro de la carpeta `src`. En [setup](./0.%20Fundamentos%20de%20la%20Programación%20en%20JAVA/1.%20Setup/README.md) encopntrarás un tutorial de cómo usar Eclipse muy completo!
